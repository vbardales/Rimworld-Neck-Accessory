# Artwork

The reproducible Preview sources are `Preview-source.png`, `echo.png`,
`ModIcon-source.png`, and `Preview.config.json`. From the repository root, run:

```text
node ../scripts/Render-Preview.cjs
```

The shared renderer writes `Mod/About/Preview.png`, `Mod/About/ModIcon.png`,
`Gallery/0-preview.png`, `Preview.ico`, and `ModIcon.ico`. Temporary checks live
under `.render/` and are not publication assets.

`Preview-necklace-source.png`, `Preview-before-icon.png`,
`Preview-before-renew.png`, `Preview-renew-source.png`,
`ModIcon-before-mascot.png`, and `ModIcon-mascot-source.png` retain the earlier
visual work and source history. `Gallery/` contains only uploadable images.
